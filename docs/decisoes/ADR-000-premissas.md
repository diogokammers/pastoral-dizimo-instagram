# ADR-000 — Premissas definidas pelo Diogo (Fase 0)

Data: 2026-09-25. Status: aceito.

## Contexto
Fase 0 concluída: leitura de `docs/marca/`. Lacunas levantadas e respondidas pelo Diogo em uma rodada.

## Decisões
- **Aprovador único:** Diogo (diogokammers@gmail.com). Também é admin da conta do Instagram.
- **Vínculo com Página do Facebook:** desconhecido; verificar na conta (Fase 1).
- **Perfil:** https://www.instagram.com/pastoraldodizimo.arquifln/ (já existe, logado no Chrome do Diogo).
- **Ritmo:** 3 posts iniciais fixados no perfil + capas de destaques; depois **2 posts de feed por semana**.
  Reels e Stories ficam manuais com a Pastoral (fora do sistema).
- **Identidade visual:** não existe manual de marca. O sistema deve produzir um **estudo e proposta de
  identidade visual e de logotipo** (paleta, tipografia, grid, logo) para aprovação do Diogo.
- **Fotografia:** artes iniciais **sem fotos** (tipográficas/gráficas). Sem imagem gerada por IA salvo aprovação.
- **Plano:** Claude **Max** hoje (pode voltar a Pro). Rota API a calcular em paralelo.
- **Doutrina:** Diogo não possui o documento da CNBB; localizar e confirmar fonte oficial na Fase 1.

## Consequências
- Gate de aprovação pode ser otimizado para uma pessoa técnica (e-mail + página de prévia é suficiente).
- Escopo de mídia do piloto: imagem única e carrossel. Reels ficam fora do render/publicação automática.
- Fase 2 ganha uma entrega extra: proposta de identidade visual + logotipo (com ADR próprio).
